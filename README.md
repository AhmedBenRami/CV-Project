# 💼 CV Project

A modern, interactive personal CV website built with **HTML**, **CSS**, and **JavaScript**. This project showcases your professional profile, skills, education, projects, and experience in an engaging and visually appealing format.

**Live Demo:** [https://ahmedbenrami.github.io/CV-Project/](https://ahmedbenrami.github.io/CV-Project/)

---

## ✨ Features

- **Hero Header**: Eye-catching introduction with profile image, name, and professional title
- **About Section**: Personal bio highlighting technical interests and career goals
- **Skills & Expertise**: Organized display of technical and professional skills
- **Academic Background**: Interactive timeline showcasing education history
- **Experiences & Projects**: Cards displaying your projects and professional experiences
- **Contact Form**: Functional contact section to get in touch
- **Loading Animation**: Smooth loading screen for better UX
- **Responsive Design**: Mobile-friendly layout that works on all devices
- **Smooth Animations**: Interactive elements with modern CSS animations
- **Dark/Modern Aesthetic**: Professional and contemporary design

## 🚀 Getting Started

### Prerequisites
- A modern web browser
- (Optional) Live server for local development

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/AhmedBenRami/CV-Project.git
   cd CV-Project
   ```

2. **Open locally**
   - Simply open `index.html` in your browser, or
   - Use a live server:
     ```bash
     npx live-server
     ```

3. **Visit the live site**
   - Open [https://ahmedbenrami.github.io/CV-Project/](https://ahmedbenrami.github.io/CV-Project/)

## 🎨 Customization

### Update Personal Information
Edit the hero header section in `index.html`:
```html
<h1>Hi, I'm <b>Your Name</b></h1>
<div class="profession">Your Title - Your School</div>
<div class="city">Your City - Your Country</div>
```

### Update Contact Information
Modify the contact details:
```html
<a href="mailto:your.email@domain.com">your.email@domain.com</a>
<a href="tel:+1234567890">+1 (234) 567-890</a>
```

### Add Your Profile Pictures
Replace profile images:
- `profile_normal.png` - Regular profile picture
- `profile_mask.png` - Masked/cropped version for styling

### Update CV PDF
Replace `cv.pdf` with your own curriculum vitae

### Modify Skills and Education
Update the data in the `json/` directory to dynamically populate:
- Technical skills
- Professional skills
- Academic timeline
- Project cards
